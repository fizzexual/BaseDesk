# BaseDesk v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship BaseDesk v0.1 — an open-source, self-hostable helpdesk (Node + SQLite server, React SPA agent workspace) — to https://github.com/fizzexual/BaseDesk.

**Architecture:** npm-workspaces monorepo. `server/` is a single Node process (Hono + better-sqlite3) exposing a REST API and serving the built SPA. `web/` is a Vite + React 19 + TS strict SPA whose Zustand store talks to a `Repository` interface (REST client by default, localStorage impl for demo/tests). All UI is built from custom design tokens, custom SVG icons, one font (Inter Variable). Spec: `docs/superpowers/specs/2026-07-11-basedesk-design.md`.

**Tech Stack:** Node 23.4+ (built-in `node:sqlite`), Hono, Vite, React 19, TypeScript strict, Tailwind CSS v4 (CSS-first), Zustand, React Router v7, Vitest, @fontsource-variable/inter.

## Global Constraints

- One font family everywhere: Inter Variable (`@fontsource-variable/inter`); tabular numerals (`font-variant-numeric: tabular-nums`) for counts/metrics.
- No third-party UI kit, icon library, or chart library. All icons: 20×20 viewBox, 1.5px round-capped strokes.
- All text/background pairs WCAG AA (≥4.5:1 body, ≥3:1 large/secondary) in BOTH themes.
- Every color/radius/shadow through CSS custom properties in `web/src/styles/tokens.css`; no hardcoded hex in components.
- Nothing hard-deletes: trash/spam are ticket `bucket` values.
- Product copy tone: plain, no exclamation marks. Ticket references in UI: `#<number>`.
- Commit after each task: `feat:`/`chore:`/`docs:` conventional messages.

### Domain types — `web/src/data/types.ts` (mirrored as `server/src/types.ts`)

```ts
export type TicketStatus = 'open' | 'pending' | 'on_hold' | 'solved' | 'closed';
export type TicketPriority = 'urgent' | 'high' | 'medium' | 'low';
export type TicketBucket = 'inbox' | 'archive' | 'spam' | 'trash';
export type Channel = 'email' | 'chat' | 'web' | 'api';
export type ViewId =
  | 'all' | 'unassigned' | 'mine' | 'snoozed'
  | 'open' | 'pending' | 'on_hold' | 'solved' | 'closed'
  | 'archive' | 'spam' | 'trash';

export interface Ticket {
  id: string; number: number; subject: string;
  status: TicketStatus; priority: TicketPriority; bucket: TicketBucket;
  requesterId: string; assigneeId: string | null; tags: string[];
  channel: Channel; createdAt: string; updatedAt: string;
  snoozedUntil: string | null; lastMessageAt: string; lastMessagePreview: string;
}
export interface Message {
  id: string; ticketId: string;
  authorKind: 'contact' | 'agent'; authorId: string;
  kind: 'reply' | 'note'; body: string; at: string;
}
export interface Contact {
  id: string; name: string; email: string; company: string | null;
  avatarHue: number; location: string | null; timezone: string | null; createdAt: string;
}
export interface Agent { id: string; name: string; email: string; avatarHue: number; role: 'admin' | 'agent'; }
export interface CannedReply { id: string; title: string; body: string; }

export interface Counts {
  all: number; unassigned: number; mine: number; snoozed: number;
  open: number; pending: number; on_hold: number; solved: number; closed: number;
  archive: number; spam: number; trash: number;
}
export interface StatsOverview {
  createdLast14Days: { date: string; count: number }[];
  solvedLast14Days: { date: string; count: number }[];
  byPriority: Record<TicketPriority, number>;
  byStatus: Record<TicketStatus, number>;
  perAgentOpen: { agentId: string; count: number }[];
  medianFirstReplyMinutes: number;
  medianResolutionHours: number;
  openNow: number; createdLast7Days: number; solvedLast7Days: number;
}
export type TicketPatch = Partial<Pick<Ticket,
  'status' | 'priority' | 'assigneeId' | 'tags' | 'bucket' | 'snoozedUntil' | 'subject'>>;
```

**View semantics** (used by store selectors AND server `?view=` filter — must match):
- `all` = bucket `inbox`, not snoozed (snoozedUntil null or ≤ now), status not `closed`
- `unassigned` = `all` AND assigneeId null AND status `open`|`pending`
- `mine` = `all` AND assigneeId = currentAgentId AND status in open/pending/on_hold
- `snoozed` = bucket `inbox` AND snoozedUntil > now
- `open|pending|on_hold|solved|closed` = bucket `inbox`, not snoozed, that status
- `archive|spam|trash` = that bucket
- Counts object = size of each view with same rules.

### Repository interface — `web/src/data/repository.ts`

```ts
import type { Agent, CannedReply, Contact, Message, StatsOverview, Ticket, TicketPatch, TicketPriority } from './types';

export interface BootstrapData {
  tickets: Ticket[]; contacts: Contact[]; agents: Agent[];
  canned: CannedReply[]; currentAgentId: string;
}
export interface Repository {
  bootstrap(): Promise<BootstrapData>;
  getMessages(ticketId: string): Promise<Message[]>;
  createTicket(input: { subject: string; body: string; requesterId: string; priority: TicketPriority }): Promise<{ ticket: Ticket; message: Message }>;
  updateTicket(id: string, patch: TicketPatch): Promise<Ticket>;
  addMessage(ticketId: string, input: { kind: 'reply' | 'note'; body: string }): Promise<{ message: Message; ticket: Ticket }>;
  createContact(input: { name: string; email: string; company?: string }): Promise<Contact>;
  saveCanned(c: CannedReply): Promise<CannedReply>;
  deleteCanned(id: string): Promise<void>;
  getStats(): Promise<StatsOverview>;
  search(q: string): Promise<{ ticketIds: string[] }>;
}
```

### REST API (server) — all JSON, base `/api`

| Method/Path | Body | Returns |
|---|---|---|
| GET `/api/health` | — | `{ok: true, version: string}` |
| GET `/api/bootstrap` | — | `BootstrapData` |
| GET `/api/tickets?view=&q=&priority=&assigneeId=` | — | `Ticket[]` |
| POST `/api/tickets` | `{subject, body, requesterId, priority}` | `{ticket, message}` (status open, bucket inbox, channel web) |
| PATCH `/api/tickets/:id` | `TicketPatch` | `Ticket` (404 → `{error}`) |
| GET `/api/tickets/:id/messages` | — | `Message[]` (ordered by at asc) |
| POST `/api/tickets/:id/messages` | `{kind, body}` | `{message, ticket}` — authorKind agent, authorId=currentAgent; `reply` sets ticket status→pending if it was open; both update updatedAt/lastMessageAt/lastMessagePreview (preview = first 90 chars of body, single-spaced, ONLY for kind reply) |
| POST `/api/contacts` | `{name, email, company?}` | `Contact` (avatarHue = hash(email)%360) |
| POST `/api/canned` / PUT `/api/canned/:id` / DELETE `/api/canned/:id` | `{title, body}` | `CannedReply` / `CannedReply` / `{ok:true}` |
| GET `/api/stats` | — | `StatsOverview` |
| GET `/api/search?q=` | — | `{ticketIds: string[]}` — LIKE over subject + message bodies + contact name/email, max 30 |

Server port: `PORT` env, default **4011**. Vite dev proxy: `/api` → `http://localhost:4011`. In production server serves `web/dist` (SPA fallback to index.html for non-/api routes). SQLite file: `${DATA_DIR ?? './data'}/basedesk.db`.
