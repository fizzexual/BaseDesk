# BaseDesk v0.2 Support→Revenue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a first-class `Deal` object and revenue surfaces (in-conversation logging, a `/revenue` section, a live money pill, revenue reports, account health) so BaseDesk turns support into a growth channel.

**Architecture:** Purely additive on v0.1. A `Deal` entity flows server (node:sqlite) → Repository → zustand store → four UI surfaces. Account health is computed client-side by grouping deals+tickets by `Contact.company`. Money is integer cents everywhere.

**Tech Stack:** Same as v0.1 — Node ≥23.4 + Hono + node:sqlite (server); Vite + React 19 + TS strict + Tailwind v4 tokens + zustand (web); Vitest.

Spec: `docs/superpowers/specs/2026-07-12-basedesk-v0.2-support-revenue-design.md`.

## Global Constraints

- Money is integer **cents** in DB/API/store; format only at render via `formatMoney`.
- Single currency USD in v0.2; `currency` field carried, not surfaced.
- Token utilities only (no raw hex / default Tailwind palette). Health badge colors: at_risk `red`, expansion_ready `blue`, healthy `green` — always label + color, never color alone.
- Deals are the one hard-deletable object; tickets/contacts still never hard-delete.
- Optimistic mutations with snapshot rollback + error toast (mirror v0.1 `patchTicket`).
- Never call `s.counts()`/`s.ticketsForView()`/`s.accounts()` inside a `useApp` selector — use memoized hooks in `web/src/data/hooks.ts`.
- Product copy: plain, no exclamation marks. Money strings via `formatMoney`.
- Commit after each task with conventional messages.

```ts
export function formatMoney(cents: number, opts?: { compact?: boolean }): string {
  const dollars = cents / 100;
  if (opts?.compact) {
    if (Math.abs(dollars) >= 1000) {
      const k = dollars / 1000;
      const s = (Math.round(k * 10) / 10).toString();
      return `$${s}k`;
    }
    return `$${Math.round(dollars)}`;
  }
  const hasCents = cents % 100 !== 0;
  return `$${dollars.toLocaleString('en-US', {
    minimumFractionDigits: hasCents ? 2 : 0,
    maximumFractionDigits: 2,
  })}`;
}

export function parseMoney(input: string): number | null {
  const cleaned = input.replace(/[$,\s]/g, '');
  if (cleaned === '' || !/^-?\d*\.?\d+$/.test(cleaned)) return null;
  const dollars = Number(cleaned);
  if (!Number.isFinite(dollars)) return null;
  return Math.round(dollars * 100);
}
```
